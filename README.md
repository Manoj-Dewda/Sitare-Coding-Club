# Sitare Coding Club Website

A modern and responsive website built for the Sitare University Coding Club to showcase team members, activities, and provide a strong online presence.

---

## Overview

This project is designed to represent the Coding Club digitally with a clean UI and structured backend. It includes pages for team members, club information, and an engaging user interface enhanced with images and media.

---

## Features

- Interactive Home Page  
- Team / Coordinators Section  
- Structured HTML Templates  
- Custom Styling with CSS  
- Background Video Support  
- Lightweight and Fast  

---

## Tech Stack

- Frontend: HTML, CSS  
- Backend: Python (Flask)  
- Templating: Jinja2  
- Assets: Images and Video

## Installation and Setup

Follow these steps to run the project locally:

### 1. Clone the repository
git clone https://github.com/your-username/Sitare_Coding_Club.git  
cd Sitare_Coding_Club  

### 2. Create a virtual environment (optional but recommended)
python -m venv venv  
source venv/bin/activate   # For Linux/Mac  
venv\Scripts\activate      # For Windows  

### 3. Install dependencies
pip install -r requirements.txt  

### 4. Run the application
python app.py  

### 5. Open in browser
http://127.0.0.1:5000/
